Launch media paths, homepage video, route banners and Stone/Article static imagery. Moved verbatim from `docs/ARCHITECTURE.md` (index) on 2026-09-26.

## Current Static Media Contract

- Published Project Storage images are delivered through `src/components/projects/ProjectResponsiveImage.tsx` and `src/lib/projectImageDelivery.ts`. Only `urblo-public-media` object URLs are rewritten to Supabase's `/storage/v1/render/image/public/` endpoint. Archive cards use 480–1280px at quality 82, list thumbnails use 240–480px at quality 82, detail/hotspot images use up to 2500px at quality 86, and heroes use up to 2500px at quality 88. All transformed requests use WebP plus fit/contain behavior; `srcset`/`sizes` lets the browser choose for viewport and pixel density. Curated local/external sources remain unchanged, and a failed transform falls back once to the retained original URL.

## Static image variants (2026-09-28)
- `node scripts/generate-static-image-variants.mjs` selects raster files of at least 100KB under `public/media/launch`, `public/products` and `public/images` whose file name is referenced from `src/`, `public/articles/` or `functions/`, and writes WebP variants to `public/media/variants/<original path without extension>-<width>w.webp` on the ladder 480/768/1200/1600/2400 (never wider than the original). Originals are kept unchanged. Encoders are fixed (photo q72, imagery under dark scrims q60, timber/galvanised finish swatches q88; effort 6, single-threaded sharp), so the same sharp/libvips version reproduces byte-identical files. When a full-width WebP is not at least 30% smaller than a JPEG/WebP original, the original itself is the top srcset candidate.
- `src/data/staticImageVariants.json` (runtime manifest: intrinsic size, variant widths, original-is-top flag) and `scripts/static-image-variants.lock.json` (source/variant hashes, encoder versions) are generated; never hand-edit them. `--check` (graph node `static-images`) fails on missing, stale, orphan or hand-edited variants without re-encoding.
- Delivery: `src/lib/staticImageDelivery.ts` and `src/components/StaticResponsiveImage.tsx` add `srcset`/`sizes`/`width`/`height` and fall back once to the original on error; unknown sources (CMS media, logos, small files) render unchanged. `getProjectImageDelivery` and `getStoneImageDelivery` use the static variants for curated local sources with their profile sizes; `prepareArticleHtml` adds srcset to rewritten newsletter images; CSS backgrounds use `getStaticImageUrl(source, boxWidth)`. First-viewport images (the Home and Capabilities heroes, the Article detail cover) are eager with `fetchPriority="high"`; below-the-fold images are lazy. Route banners were retired on 2026-09-28.
- To replace a photograph, add it under a new file name, update the reference and regenerate; do not overwrite an original in place (variant URLs derive from the original name).
- Cache headers: no project-authored `Cache-Control` is added. Missing `/assets/*` and `/media/*` paths still return the SPA shell with HTTP 200 (`_redirects` `/* /index.html 200`), which is how the 2026-07-13 custom-domain cache incident poisoned hashed asset URLs; a long or immutable cache on those prefixes stays blocked until a missing-asset path returns a real 404 (see `docs/architecture/delivery.md`).
- Fonts: the Avenir LT Std and Didot LT Std TTFs are Adobe/Linotype desktop fonts (name table: Adobe copyright, Heidelberger/Linotype trademark, licence URL adobe.com/type/legal.html, `fsType` 4 = preview and print embedding). No web-font licence is recorded in the repository, so they are not converted to WOFF2 or subset (conversion modifies the font software) and no preload is added. Converting or preloading needs Jay to confirm a web licence that permits it.
